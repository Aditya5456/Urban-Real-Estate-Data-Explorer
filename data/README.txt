DATASET NOTES

The required source dataset is Kaggle's "House Prices: Advanced Regression Techniques" competition:
https://www.kaggle.com/c/5407/data

Download the official train.csv from Kaggle and place it in this folder if you want to work from the original download. Kaggle may require a signed-in account and acceptance of competition rules.

train_sample.csv is a 60-row subset of the Kaggle-format training table included so the app runs immediately. It is not synthetic. The full local data/train.csv is intentionally excluded from Git using .gitignore; do not publish competition data unless Kaggle's current terms allow it.

The optional full `train.csv` should contain the `SalePrice` column and 1,460 records. The website can also analyze other CSV files through its upload control.
